# Learning Rust with an Arena Allocator

A learning project to pick up **Rust** starting from a C background by building an **arena allocator** step by step with gradually increasing complexity.

## The Idea
Instead of only reading theory or doing isolated exercises, I'm using this repository as a hands-on logbook:
- start with a minimal, working version;
- add features, checks, and improvements in small steps;
- track the evolution through commits so I can see how the code—and my understanding—grows over time.

This isn't meant to be a production-ready allocator, just a personal playground to get comfortable with the language and how it works under the hood.

## Progress & Notes
Each commit or milestone marks a step along the way. Technical details, design choices, and notes on what I run into will go right here as the project evolves.
